# Prompt 1: LinkedIn Post for Product Launch

## Use Case
Write a LinkedIn post announcing a product launch.

## Techniques Used
Role + Few-shot + Constraints

## Template

You are a senior LinkedIn content strategist.

Write a LinkedIn post announcing the launch of {product_name}.

Product Description:
{product_description}

Target Audience:
{target_audience}

Constraints:
- Maximum 120 words
- Use short paragraphs
- Add one emoji
- End with a CTA
- Do not use words like "Amazing" or "Excited"

## Sample Output

📚 Introducing our **Library Management System**! 🚀

Managing books has never been easier. Our digital solution helps students quickly find and borrow books while enabling librarians to organize, track, and manage library resources efficiently.

Designed for college students and librarians, this system saves time, reduces paperwork, and makes library management smarter and more accessible.

Ready to transform your library? Try the Library Management System today and share your feedback!

## Iteration

v1:
Basic LinkedIn post prompt.

v2:
Added role, target audience, CTA, emoji, and word limit.

Improvement:
The output became more engaging, structured, and reusable.

# Prompt 2: Product Description

## Use Case
Generate a product description for an online shopping website.

## Techniques Used
Role + Constraints

## Template

You are an experienced e-commerce copywriter.

Write a product description for {product_name}.

Features:
{product_features}

Target Audience:
{target_audience}

Constraints:
- Maximum 100 words
- Highlight customer benefits
- Use simple English
- End with a CTA

## Sample Output

### Wireless Bluetooth Earbuds

Experience crystal-clear sound with Bluetooth 5.3, active noise cancellation, and up to 20 hours of battery life.

Designed for students and professionals, these earbuds provide a comfortable fit, fast connectivity, and immersive audio for music, calls, and online classes.

🎧 Upgrade your listening experience today. Order now!

## Iteration

v1:
Asked only for a product description.

v2:
Added customer benefits, target audience, and CTA.

Improvement:
The description became more persuasive and customer-focused.

# Prompt 3: YouTube Title and Description

## Use Case
Generate a YouTube video title and description.

## Techniques Used
Role + Zero-shot + Constraints

## Template

You are a YouTube SEO expert.

Generate a YouTube title and description for:

Topic:
{video_topic}

Target Audience:
{target_audience}

Constraints:
- Title should be under 60 characters.
- Description should be under 150 words.
- Include 5 hashtags.
- Use SEO-friendly keywords.

## Sample Output

### Title

Python for Beginners | Complete Tutorial in Tamil

### Description

Learn Python programming from scratch with simple explanations and practical examples. This beginner-friendly tutorial is perfect for college students preparing for exams and placements.

Watch till the end for coding tips and practice examples.

#Python #Programming #Coding #Tamil #Beginners

## Iteration

v1:
Generated only a basic title and description.

v2:
Added SEO keywords, hashtags, and character limits.

Improvement:
The output became more attractive and easier to discover through YouTube search.
